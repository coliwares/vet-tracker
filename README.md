# Vet Visits Tracker

Registro simple de visitas veterinarias para tus perritas. Funciona offline y guarda todo en LocalStorage.

## Funcionalidades

- Dashboard con métricas, tarjetas de resumen y filtro por rango (30/90 días, año, todo).
- Historial de visitas con búsqueda, filtros por perrita y total filtrado.
- Registro de nuevas visitas con validación y datos clínicos (diagnóstico, tratamiento, costos).
- Perfil de perritas en cards con edad calculada y acceso directo al historial.
- Respaldo e importación de datos en JSON para mover o restaurar información.

## Requisitos

- Node.js 20+ recomendado.

## Cómo ejecutar

```bash
npm install
npm run dev
```

Luego abre el enlace que muestra Vite (por defecto http://localhost:5173).
